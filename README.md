# WizardCardGame - Software Process Engineering Interactive Report

This orphan branch (`docs`) hosts a **Astro Starlight** technical report for the **Software Process Engineering (SPE)** course at the University of Bologna.

## Local Development

```bash
# Install dependencies
npm install

# Start local development server with hot-reload (http://localhost:4321/report)
npm run dev

# Build static site for production (output in ./dist)
npm run build
```
