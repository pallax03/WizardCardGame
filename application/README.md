
# Frontend

```bash
npm run dev
```

## Dependency

### Installed

- [Shadcn UI: Base UI](https://ui.shadcn.com)

### Not Installed

- Socket.IO: WebSockets
- framer-motion: drag and drop animation
- zustand: Middleware and Manager Socket
- canvas-confetti: win animation

## Custom Components Shadcn UI

- **bubble**: for text chat!!!
- **avatar**: for username initials avatar.
- **sheet/drawer**: scoreboard.
- **progress**: for displaying timer.
- **badge**: for displaying fast info (scores, or trump, etc.).
- **tooltip/popover**: for displaying additional information.

### Custom hooks in 'ui/hooks'

- useHapticFeedback: for vibration feedback on mobile devices.
